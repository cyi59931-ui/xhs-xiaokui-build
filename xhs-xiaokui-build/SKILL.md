## 二、账号定位(Building Block 1:选什么赛道、立什么人设)

### 2.1 赛道逻辑:为什么选美食测评×避雷
- **高共鸣高痛点**:奶茶/汉堡/杨梅/鹅腿…都是大众高频消费,"花了钱踩到雷"的痛感人人都有,自带"我被坑过"的代入感。
- **红海里切差异化**:"哪家好吃"是众说纷纭的红海;"把好坏拆成可判级的标准"稀缺,教方法论 = 辨识度 & 评论区的"交卷"自证。
- **素材取之不尽**:一切入口之物都能"切一刀"评级——单品、时间、PK、工艺、智商税,题材无限。
- **高收藏高转发**:五级图鉴/定级表/避雷清单给"存下来下次对表";"别被颜值骗""花钱买炸面粉"给转发安利。

### 2.2 定位框架(可套用)
```
【一句话定位】专注【美食好坏判定】的【避雷测评】账号,帮【人群】在消费前【看懂好坏、不花冤枉钱、不被套路】。
【人群】奶茶/小吃/快餐等高频美食消费者;爱比价、怕踩雷、爱看测评/避雷的实用主义年轻人;甜品与小吃爱好者。
【核心痛点】"同样是××,为啥我买到的又难吃又贵?""宣传图封神、入口像在嚼情绪""被智商税和网红包装骗了又骗"。
【差异化立场】不无广不掺水、只讲自费实测的方法论:"好坏直说不掺水";把口味玄学变成"夯到拉"的可判级标准。
【一句话简介模板】好坏直说不掺水,关注【昵称】【评级黑话】爆了!
```

### 2.3 人设三件套(立信任的关键)
1. **自费实测 + 数量背书**:"我自费喝了 50+ 杯""50 组实测""两只整腿拆开了测""干这行…"——用"我为结论自己掏过钱"立真实测评人设(#02 #08 #24)。
2. **敢说真话的避雷承诺**:"好坏直说不掺水""无广实测""永久避雷""别被颜值骗"——敢点名敢拆穿,与软广种草号划清界限(#17 #23 #25 #32)。
3. **给方法论而非结论**:不是"这家好吃",而是"一咬回弹看夯顶,内外不一掉 NPC,硬芯软烂直接拉"——把经验教给读者,读者用 ta 的方法独立"判级",立专业权威(#02 #01)。

### 3.2 五级金字塔评级引擎(本号最核心的"手艺",务必贯穿每篇)
**每一篇都先用同一个五级坐标,再填充具体判据**:
```
👑 夯级(封神/闭眼无脑冲) → 🔥 顶尖(日常能打/稳定不翻车) → 🤔 人上人(不惊艳但也没翻车/不坑但不值得专门跑) → 😶 NPC(记不住/可有可无/纯凑数) → 💀 拉(判死刑/永久拉黑/直接避雷)
```
- **交叉定级维度**:不靠主观一句,给 3 个可操作维度再判(例 #02:回弹感→内外一致性→咀嚼残留感;#24:嫩度→入味→香气→性价比,满分制)。
- **视觉证据化**:能"切"就切——断面/切面/对照图/金字塔图,图片即定级依据(#01 #30 #29)。
- **速记口诀**:一句话让读者带走方法,如"一咬回弹看夯顶,内外不一掉 NPC,硬芯软烂直接拉"(#02)。
- **懒人三步定级法**:把方法压到"拿到手怎么做"的行动指令(#02)。
- **落点永远是"你自己能判"**:不是"听我的",是"收藏这张图,下次你对表判级"——把权威让渡给读者,反而更权威。

### 3.3 写作引擎(DNA 逐条)
- **痛点开场先接住**:"你是不是也这样——满心欢喜加了份芋圆,结果咬一口直接破防"(#15)、"你是不是也怕:宣传图封神、入口像在嚼情绪"(#31)、"赶时间进店随手点个芋泥啵啵杯,结果喝到一口拉"(#32)。
- **"讲真的"承接观点**:口语化"讲真的/直接说结论/别乱试"快速给答案(#09 #16 #20 #21 #30)。
- **标签式分层写作**:编号 + 评级徽章 + 一句判据 + 情绪词(太上头/闭眼冲/永久避雷),信息流里一眼可扫。
- **结论前置 + 懒人清单**:先给"结论先拍"再给过程(#09 6h 封神→2h/12h 人上人→24h 大雷;再给"懒人必买清单+避雷清单")。
- **双关与梗**:J 越大越甜=樱桃等级/双关(#26)、屈原吃螺蛳粉粽子写《离骚2》(#21)、世界杯用球也上五级(#19)——用梗做打开率,用母题做系列感。
- **评论区"交卷"互动**:"你上次喝的奶茶里那颗芋圆,对着图鉴是哪一级?评论区交卷""回来交作业,我看看谁能喝到夯级""你是腿根党还是腿梢党?"(#01 #02 #24)——低门槛站队,灌评论养权重。
- **金句/黑话收尾**:"夯到拉""永久避雷""别被颜值骗""花钱买炸面粉""好坏直说不掺水"——注册"夯/拉"黑话,强化记忆点。
- **统一话题标签组**:#从夯到拉 #美食解构主理人 #美食SOP指南 #拒绝科技与狠活#美食测评……(同批笔记标签高度一致 = 系列化)。

## 四、增长设计(Building Block 3:怎么从0到获赞)

1. **批量铺稿冷启动**:32 篇单日集中铺满 7 类矩阵,主页即"避雷图鉴墙",打开即标准大全。
2. **避雷清单拉收藏**:五级图鉴/时间金字塔/对照图/避雷清单全是"存下来对表"的内容,收藏属性天然强。
3. **站队投票养权重 + 造选题**:每条结尾给二选一/拍级/找茬交卷,评论即选题池("腿根党还是腿梢党"→下条按票数拆)。
4. **热点借势**:鹅腿阿姨塌房(#23)、端午节猎奇粽(#18)、世界杯用球(#19)——蹭热搜与节日,白嫖搜索与话题流量。
5. **黑话建立心智**:持续输出"夯/拉/封神/NPC/人上人/永久避雷",让读者形成"评判美食前先问小葵"的条件反射。
6. **系列化 + 破圈**:同一五级母题在奶茶/甜品/肉类/水果/甚至足球间横跳,"万物皆可夯拉"制造连续剧感;同发布时间瀑布流强化"权威指南"观感。
7. **AI 图解量产**:切面图/金字塔图用 AI 生成(平台自动加"可能含AI生成内容"标注),用标准化模板把单篇生产成本压到极低,支撑日更量。

## 五、避坑红线(所有建设动作遵守)

- 不无广掺水是立身之本:一旦被查接软广/好评置换,人设崩塌;初期一律"无广实测、自费"。
- 不编造实测数据:自费杯数/组数口径要真实统一,单品的定级结论与配图一致,不夸大翻车效果博流量。
- 指名道姓要谨慎:拉踩具体品牌可以(小葵式"汉堡王丑椒""某联名款")但要基于真实试吃,不做无证据的指控,避免商誉纠纷。
- AI 图合规:AI 生成图按平台要求标注;切面/金字塔示意不冒充真实拍摄实物对比。
- 不制造"食物恐慌":拆穿智商税可以,别升级成"这不能吃那全是雷"的焦虑贩卖;种草与避雷平衡,避开"科技与狠活"极端化叙事。
- 人设要稳:自费实测/直说真话/交作业三件套贯穿,后期接评测必须标注合作,不接与既有"避雷"立场冲突的软广。
- 评论区引导注意引导性提问即可,不引导攻击具体商家。
